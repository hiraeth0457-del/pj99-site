プライバシーポリシー

PJ99（作者本人だけが使う個人用アプリ）

1. 対象

PJ99 は作者が自分のために作り、作者本人だけが使うアプリです。作者以外の人のデータは扱いません。

2. 使う Google のデータ

  • Google カレンダー（calendar.readonly・calendar.events）：予定の読み取り、作者に頼まれたときの予定の追加・変更
  • Gmail（gmail.readonly）：受信メールの読み取り（送信・削除・変更はしません）

3. 使い方

  • 作者への返事、予定の確認、大事なメールや支払いのお知らせを作者に知らせるためだけに使います。
  • 返事を作るために、必要な部分を AI モデルの提供元（OpenRouter を通じて呼び出す言語モデル）に送ることがあります。送るのはその返事に必要な範囲だけです。
  • 広告、販売、第三者への提供、AI モデルの学習用データの作成には使いません。

4. 保存

  • 認証情報と、アプリが作った記録（会話・メモなど）は、作者の自宅PCの中にだけ保存します。
  • 作者は、Google アカウントの設定からいつでもこのアプリのアクセスを取り消せます。取り消したあとは Google のデータを読みません。

5. Google API Services User Data Policy

PJ99 による Google API から受け取った情報の使用と他のアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

6. 連絡先

このページについての問い合わせは、GitHub の Issues へお願いします。

English summary

PJ99 is a personal app used only by its developer. It accesses the developer's Google Calendar (read, and add/change events on request) and Gmail (read-only) solely to assist the developer. Relevant parts may be sent to AI model providers via OpenRouter only to generate the assistant's replies. Data is never sold, used for advertising, shared with third parties, or used to train AI models. Credentials and records are stored only on the developer's home PC. Access can be revoked at any time from the Google Account settings. PJ99's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: GitHub Issues of this repository.
